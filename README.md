# MI_3103 — Procesos de Manufactura

Repositorio para los materiales del curso MI-3103 Procesos de Manufactura.

## Estructura

- `Assignments/` — Assignments
- `Class_Project/` — Class Project
- `Evaluation_Rubrics/` — Evaluation rubrics
- `Exams/` — Exams
- `Homeworks/` — Homeworks
- `Short_Tests/` — Short tests
- `Supervised_Exercises/` — Supervised exercises
- `Templates/` — Shared TEC LaTeX templates
- `Week_Assignments/` — Week assignments

## LaTeX

Documents use the shared `latex-templates` repository as a Git submodule.

The course documents are compiled using XeLaTeX through `latexmk`.
